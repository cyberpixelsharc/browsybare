# 0.3.0 (2026-09-23, first release)
- First public release: a minimalist Kodi skin that turns Kodi into a file manager (no library, no scrapers)
- File manager: single Home window with drive chip, breadcrumb, search, sorting, folder sizes, file operations, hamburger menu, own on-screen keyboard
- Players: audio footer overlay, fullscreen video with its own OSD, dedicated photo viewer (EXIF orientation, Ken Burns, recursive slideshow, OSD) -- plus a shared file-direct INFO modal (tags, stream info, embedded covers, EXIF)
- Settings: own dialog with 5 tabs (General, Player, Sources, Blocklist, Remote); sources (local drives, directory and network shares), blocklist, remote key learning, accent color
- The Estuary base layer (Kodi settings, player core, system dialogs) is taken over at runtime; its windows follow the chosen accent
- Languages: English, German, French, Spanish (interface strings and matching on-screen keyboard layouts); other Kodi languages fall back to English
- Install as an addon zip or copy the folder to addons/<id>/, then switch the skin to Browsybare (Estuary stays installed)
