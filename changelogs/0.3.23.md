# 0.3.23 (2026-10-07, release)
- The GitHub link in the About modal now opens the system browser on Android/TV via Kodi's Android view intent, instead of failing with "no browser found" (Python's webbrowser cannot reach the system browser there).
- Internal robustness fixes from a full code review: a network path whose name contains an "@" is parsed correctly again; a WebDAV folder cut/paste can no longer lose the folder (a completed server-side move is trusted, and the source is only deleted once the copy is verified at the target); deletes on WebDAV report their real result; and the volume is no longer nudged (or muted at 1-3%) on every start.
- Hardened the update-zip handling (reject Windows-style path traversal and XML entity expansion in the downloaded add-on XML) and bounded the media metadata reads so a crafted file cannot allocate large buffers.
- Renaming a file or folder on a WebDAV source to a name with a special character (for example "@") works now: the rename uses the skin's own request, because Kodi's rename mangles the encoded name.
