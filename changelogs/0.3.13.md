# 0.3.13 (2026-10-04, release)
- Updater reworked: the About button now downloads the new release into Kodi's own temp folder (with a writable fallback to the OS temp folder, so it works on every platform) and installs it directly over the skin, then reloads -- no more saving into a `Downloads` folder that a sandboxed Kodi (e.g. Ubuntu) cannot see, and no manual "Install from zip". The zip is verified (addon id + version) and staged first, so a broken download can never leave a half-updated skin; the "Downloading"/"Installing" labels stay visible for at least a second each so the progress is readable even on a fast update
- The audio and photo player loading spinners sit at the same height as the folder-loading spinner -- they were centred on their full overlays and so sat too high
- The About update button shows "Searching for update" for at least 2 seconds while it checks GitHub (so a fast reply does not make it flash by), then switches to "Download %s" or "No new version available"; its idle label is now the singular "Check for update" / "Nach Update suchen"; the update button is wider so longer translations (French, Spanish) cannot overflow its pill
