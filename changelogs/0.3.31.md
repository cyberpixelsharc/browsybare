# 0.3.31 (2026-10-11, release)
- The skin now ships a background wallpaper (`media/wallpaper/wallpaper.jpg`, a compass-rose composition). Until you pick your own folder, the first image in that folder is used, black and white at 10 % visibility and filled to the screen (aspect kept, overflow cropped, so it is never squashed); a reset of the Background section brings it back. Picking a folder also selects its first image right away, so the wallpaper no longer goes blank between folders, and the "Image" row picks a random wallpaper from the folder instead of stepping in order. The visibility now goes up to 20 % (was 15 %).
- Fixed the wallpaper sticking to an old image after its file was replaced at the same path: the local cache is now refreshed when the source file changes (mtime + size), while still serving the cached copy when the source is offline.
- Centred every loading spinner (folder list, wallpaper, photo, audio) on the screen: they use `centerleft`/`centertop` 50 % now, so they sit in the exact middle on any aspect (they used to sit slightly above the middle on a 16:10 screen).
- Fixed the folder picker's header navigation: pressing Right from the breadcrumb jumped straight to "Cancel" (skipping "OK"), and pressing Left from "OK" stayed on it. The order is now breadcrumb -> "OK" -> "Cancel" (and wraps around).
