# 0.3.18 (2026-10-05, release)
- SMB, NFS, FTP and WebDAV folder listings use the plain path again: the trailing slash that the previous release added for SFTP is now applied only to SFTP, because the other network backends break or behave differently with it. SMB was verified end to end -- browsing, audio/video/photo playback, copy/move and folder create/rename/delete (NFS and FTP are not field-tested yet).
- A network source whose protocol needs a separate Kodi add-on now says so: opening an SFTP source while the `vfs.sftp` add-on is not installed or disabled shows "The required add-on is not installed or disabled (vfs.sftp)" -- both in the file browser's error row and when pressing Test in the source editor -- instead of a generic "connection error".
- Network folders now fill in file sizes and dates reliably: the background scan only runs (and only puts a folder on its two-minute cooldown) while the UI is idle and after a complete pass, so an aborted pass no longer leaves the values blank for minutes; and folders with more than 60 new entries keep filling on the next pass instead of stopping at the first 60.
- A file you copy, move, rename, delete or create in a network folder gets its size and date right away: the operation tells the background scan to forget that folder's cooldown, so the new entry no longer sits with "…" until the cooldown expires.
- The on-screen keyboard can paste: with it open, press Ctrl+V (Windows/Linux) or Command+V (macOS) to drop the system clipboard into the field; line breaks become spaces. Desktop only -- Android/TV devices have no system clipboard.
- The hardware Backspace key now deletes while editing a network source too: in the source editor (settings dialog) it used to fall through to the global "Back" and closed both the keyboard and the settings window.
- The hardware ESC key now cancels the on-screen keyboard instead of closing the window below it (same missing binding as Backspace in the source editor).
