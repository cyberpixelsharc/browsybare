# 0.3.32 (2026-10-11, release)
- Fixed the settings tab captions in fullscreen. Each tab had two overlapping labels (active accent / inactive grey) at the same place; swapping one for the other made Kodi lay the text out a hair differently, so the caption shifted a few pixels to the right and clipped its last letter. The captions are now a single label per tab, coloured through a window property the skin keeps for the active tab (accent) and the others (dim), with a space of padding on each side (a centred Kodi label clips its last glyph at its own text edge). No more shift, no clipping -- windowed and fullscreen. The labels stay 190 px wide so the long translations (it/ro "Telecomando/Telecomandă") plus the padding fit.
- Renaming a file on a network source (e.g. WebDAV/Shadow Drive) now shows the new name right away. The rename itself worked, but the browser served its cached listing (up to 5 minutes old) and, while the cache was still fresh, skipped the background refresh, so the old name stayed on screen. A network rename/create/delete now drops that folder's listing cache (`common.listing_drop` via `fileops._net_changed`), so the list re-fetches.
- The dim backdrop behind modals and menus is now a single fixed neutral gray (`sync.THEME_VEIL` = `80101010`) instead of a per-theme colour (it used to be the theme's own tinted `veil` role, e.g. ForestNine's blue-gray `80101416`). Opening a modal therefore no longer casts a colour over the dimmed file manager and top bar. `veil` is no longer a theme role (dropped from `themes/*.json` and `THEME_ROLES`); the XML still reads `bp.theme.veil`, which `sync.themes` now sets to the constant.
