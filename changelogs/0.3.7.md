# 0.3.7 (2026-09-26, release)
- Continue watching: when a video or audio file has a saved position (last 7 weeks), a "Playback" prompt offers Resume / Restart; positions are stored locally in an own hashed JSON file (no plaintext names)
- Update check can download the newer release zip into the user's Downloads folder (with a confirmation prompt and OS fallbacks), for manual installation
- Logs no longer contain plaintext paths or file names (masked at the source and centrally)
- Fixed: a network source without an address was stored as a bogus `ftp://` entry (and blocked a second one); it is now a valid path-less entry
- Fixed: VBR AAC duration/bitrate were wrong (bounded frame sampling instead of a first-frame estimate)
- Hardened: network delete reports failure only when the target still exists; source-root/drive handling keeps a bare `ftp://` scheme intact
