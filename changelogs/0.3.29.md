# 0.3.29 (2026-10-10, release)
- Added 18 more interface languages: Italian, Dutch, Polish, Portuguese (Portugal and Brazil), Russian, Swedish, Danish, Norwegian (Bokmål), Finnish, Czech, Turkish, Hungarian, Slovak, Slovenian, Bulgarian, Greek and Romanian -- 22 languages in total. Each ships translated strings, the add-on summary/description and its own on-screen keyboard layout (Cyrillic for Russian and Bulgarian, Greek for Greek).
- The in-app update now removes theme files that are no longer shipped (a release can drop or rename themes, and the update used to leave the old files in place, so they kept showing in the theme switch). A write-protected file -- e.g. your own theme -- is left untouched. If the theme you had selected was one of the removed ones, the setting now falls back to the default.
- Shortened translations that clipped in the narrow settings tabs and rows (the tab widths and fonts are fixed): the Player, Blocklist and Remote tabs plus the interface-volume and fullscreen-visualisation rows in several languages. A new offline check (`dev/test-lang-widths.py`) measures every localized label against its control and flags overflows.
