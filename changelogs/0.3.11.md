# 0.3.11 (2026-10-02, release)
- The install veil and the skin-keep dialog are readable from the first frame: the theme colours are applied before the base sync, so they are no longer colourless for the first seconds on a fresh install
- Android drive sources reworked: the home source is now the shared storage (the app-private home folder is empty there) and the separate "Internal storage" entry is gone; only real removable volumes (SD/USB) appear as drives -- including an OTG USB stick that is mounted outside `/storage` -- and they now show their real volume name (the same name the file browser shows)
- Non-16:9 screens: a skin resolution entry for 5:3 panels (e.g. 2000x1200 tablets) keeps round buttons round, full-screen backgrounds now reach the bottom so there is no dark band, and the audio-player and photo-viewer footers sit flush at the bottom
- The photo viewer's on-screen controls are bottom-anchored and no longer flash for a moment before hiding
