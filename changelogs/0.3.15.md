# 0.3.15 (2026-10-04, release)
- The install/base-sync veil ("Installation und Fusion") is now fully centred: its header and progress bars used fixed positions tuned for 1080p, so on taller screens (5:3, 16:10, 3:2, 4:3) they drifted off the centred panel.
- Added skin resolutions for 16:10 (1920x1200), 3:2 (1920x1280) and 4:3 (1920x1440), and made the full-screen dim/fill backdrops fill the real grid height (they used a fixed 1152). On screens whose aspect is not covered Kodi stretches the layout, so round buttons showed as slightly tall ovals and a thin band was left at the bottom; with a matching resolution both are gone (16:9, 5:3 and 15:9 were already covered).
- The About update texts now name the version and read more clearly: the button shows "New version %s available" (was "Download %s"), the confirmation asks "Download and install the new version %s?", and the progress is "Downloading version %s" -> "Installing version %s" -> "Version %s installed". All four languages (en/de/fr/es).
- New opt-in "Automatically check for updates" (General settings, off by default): once per session, shortly after start, the skin checks for a newer release in the background and, if one exists, opens the same install confirmation as the manual check (nothing installs without a Yes). Only offered while the file manager is idle (no player, no open dialog) and never repeated for the rest of the session if declined. It is reset by the "System and Kodi" rubric's eraser together with the other settings there.
- Dropped the unused string 31525 ("New version available: %s").
