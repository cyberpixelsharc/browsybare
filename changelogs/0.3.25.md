# 0.3.25 (2026-10-08, release)
- Fixed the automatic update check, which had stopped running after the last code review: a blacklist state marker (set at every start) was wrongly treated as an open dialog and blocked the check on every device. The check also now waits for the file manager to be idle and logs why it skips.
- Added an optional fullscreen visualisation for the audio player. A "Fullscreen visualisation" row in the audio settings cycles through Off and every installed visualisation add-on (like the theme switcher), showing the current one. With a visualisation selected, Backspace during audio opens it fullscreen; Back returns to the file manager with playback continuing. With "Off" (the default) Backspace keeps closing the player as before. Install visualisations from the Kodi add-on repository (projectM, Milkdrop, Shadertoy, Spectrum, Waveform, ...); the row picks them up automatically.
- Closing the fullscreen visualisation with Back or ESC is now reliable. Kodi's default visualisation keys map Backspace to a Fullscreen toggle (plus a long-press Stop) and Escape to an invalid action, so it sometimes took several presses; the skin now maps Back/Escape straight back to the file manager.
- In the fullscreen visualisation, the V key now toggles the visualisation's own settings (Kodi's default only opens them); Back and ESC close reliably.
- Kodi's core modals (select dialogs such as the visualisation preset list, and the add-on settings) now follow the skin theme: their dialog surface uses the selected theme's panel colour instead of Estuary's fixed dark colour (the accent was already themed).
- Went a step further on the core modals: their titles now use the skin's modal font and the simple-list text follows the theme's text colour (in addition to the themed surface/accent).
- Replaced Kodi's vendor logo in the top-right of the core dialogs with the close X (the header close button now shows the X in every state, not Kodi's logo).
- The select dialogs (e.g. the visualisation preset list, P) now use a Browsybare-styled window (our panel/header/rows/scrollbar/buttons) instead of the Estuary base dialog.
- The add-on settings dialog (V) now uses a Browsybare-styled window (our panel/header/categories/buttons) too.
- The focus highlight (the accent tint on the selected row or button) is more visible throughout the skin, including the on-screen keyboard.
- Our own OK and confirm dialogs now use the selected accent colour (they still had a hard-coded blue).
