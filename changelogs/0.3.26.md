# 0.3.26 (2026-10-09, release)
- The audio player now honours the shuffle setting when it builds the playlist: with shuffle on, starting a folder plays in random order instead of always beginning with the clicked file and then the folder order.
- The video player honours the shuffle setting the same way.
- Fixed toggling shuffle off: after switching it off and picking the next title, a random one kept playing because the running playlist was not rebuilt. The shuffle button now rebuilds the playlist in the new order.
- Shuffle now survives a Kodi restart. The skin reads the real shuffle flag (Kodi's own, independent of the active playlist) and toggles it through Kodi's native control, so Kodi stores it again.
- Mute can be switched off again at volume 0 (Kodi reports the player as muted at 0, which used to wedge the button).
- Volume and mute are fully decoupled: the mute icon now reflects the actual mute state on its own, independent of the volume level.
- Pressing Up from the header (drive, breadcrumb, search, menu) now jumps back to the audio footer while music plays.
- Pressing Up from the audio footer focuses the playing item in the file list.
- The file list now follows the playing audio track: on every title change the playing row is focused briefly and the focus returns to the footer, so the list keeps up with playback.
- The fullscreen visualisation can be opened by tapping the audio footer, and closed with a tap.
- Notifications now use the skin name ("Browsybare") as their heading; the network source editor keeps its "Networks" heading.
