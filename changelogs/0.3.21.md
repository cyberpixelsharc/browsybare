# 0.3.21 (2026-10-07, release)
- The "Automatically check for updates" option now sits at the top of its "System and Kodi" section, where it is no longer easy to overlook (it was the last row).
- The automatic update check, the background helpers (folder sizes, home refresh) and boot notices are now launched through the skin's own add-on path instead of `special://skin`. During the brief base-layer merge the active skin is momentarily Estuary (which has no `scripts/main.py`), so a `special://skin` launch silently failed there and the automatic update check could never start.
- Opening an unreachable network source (for example while on the wrong network) no longer leaves the list spinning for a long time: a quick reachability probe now fails fast and shows the connection error right away.
- Back / ESC now cancels a list that is still loading and returns to the folder you came from (previously Back did nothing while a source root was loading).
- Deleting, renaming, creating a folder or pasting on a network source whose host has gone away now fails cleanly instead of crashing Kodi (Kodi's `vfs.sftp` crashes on a delete against a dead host).
- Cancelling the network-source editor now returns focus to the source row you were editing, like OK does (it jumped to the + button instead).
