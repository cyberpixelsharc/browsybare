# 0.3.27 (2026-10-09, release)
- Added a "Crossfade" option to the audio player: a cycle row in the audio settings (Off, 6, 8, 10, 12 or 14 seconds) blends one track into the next, so an album or playlist flows without hard cuts between songs.
- Fixed the fullscreen visualisation: closing it with Back returns the focus to where it came from (the audio footer) instead of jumping to the drive chip in the top-left corner.
- In the fullscreen visualisation, the remote's Menu button now opens the visualisation preset list, the same as the P key.
