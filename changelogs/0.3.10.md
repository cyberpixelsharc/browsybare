# 0.3.10 (2026-09-29, release)
- File operations now work between local drives and network sources, and between two network sources: copy, cut and paste for files and folders, in both directions, with a progress bar
- Uploads to WebDAV servers work again -- the skin performs the upload itself, because Kodi's own WebDAV write path fails on servers that require authentication
- Network copies are more resilient: transient server errors are retried, a copy that was interrupted can be resumed (a destination already holding the file is recognised), and a failure reports the actual reason
- The confirm windows behind the power/quit menu and the shutdown timer take focus immediately
- Appearance and colors gains a theme switch: a light, a medium and a dark palette (`LightPearl`, `MediumOvercast`, `DarkNightfall`) recolour the whole skin live, the file list and menus included. Each theme is one commented JSON file in `themes/` that you can copy and edit to add your own; the default is `MediumOvercast`
- The shutdown/power menu now follows the active theme instead of fixed colours
