# 0.3.9 (2026-09-27, release)
- WebDAV/network sources: listings are much more reliable (transient server errors are retried, and an empty folder is shown as empty instead of "unreachable"); servers that require Digest authentication now work
- WebDAV files whose name contains special characters (e.g. `;`) are shown with their full name and play correctly (they were truncated before)
- Network sources: copy/cut/paste is supported on writable sources (a server-side move/copy is used where possible)
- Playback: background folder scanning pauses during playback and while a network track is still loading, so network tracks no longer fail to start; the loading indicator stays until playback really starts and the audio bar appears right away
- Update download: saves into your existing `downloads` folder; the confirmation shows the real target folder, and the file list refreshes after the download
- Fixed: renamed, created or deleted items appear or disappear immediately (the list refresh order was wrong)
- Fixed: modal buttons and the on-screen keyboard take focus immediately instead of after a short delay
- Fixed: the release zip now carries explicit folder entries, which fixes an intermittent install failure (black screen) on some boxes
