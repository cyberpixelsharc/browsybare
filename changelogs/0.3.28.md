# 0.3.28 (2026-10-09, release)
- Fixed the list-follow: it now clears the header/footer overlay reliably. The list is focused before the nudge, both sides are nudged in turn, and the nudge may scroll into the bottom padding rows, so a track near the end of the list also scrolls clear of the footer.
- A file or folder whose size has not been read yet no longer shows a "…" placeholder in the list; the size column now stays empty (like the modification date), instead of three dots.
- Reworked the shipped themes: seven colour families, each in a light, a medium and a dark variant (ForestNine, PaperCream, GoldenHour, ObsidianMist, SunriseCloud, MorningFrost, DaybreakBlue). The default theme is now ForestNineMedium.
- The default accent colour is now green (was blue).
- Removed a leftover blue from the base palette: the player seek bar, the install progress bar and a few base-layer windows could still show the old blue accent; they now follow the selected accent (and the shipped palette defaults to green).
