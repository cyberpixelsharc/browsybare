# 0.3.12 (2026-10-03, release)
- Slow network folders now show a loading spinner over the list, and the list stays covered until the folder is actually read -- on very slow sources it could briefly reveal an empty list and the new folder name first
- Non-16:9 screens: every dialog (shutdown menu, confirm, notice, timer, delete, about, resume, context menu, shortcut map, on-screen keyboard, settings, network-source editor) is centred on the real screen height instead of a fixed 1080 grid, and the shutdown menu's dim backdrop reaches the bottom
- The audio player's loading overlay dims right down to the footer on any aspect (on a 5:3 screen a thin undimmed bar had appeared above the footer while a network track loaded)
- Android: removable volumes are opened through the mount path Kodi itself uses, so an SD card that is empty via the public `/storage` view (e.g. an encrypted or portable card) now shows its content; volumes with no readable path are skipped instead of appearing empty
- Switching a settings tab no longer flashes the focus to the tab's first item
