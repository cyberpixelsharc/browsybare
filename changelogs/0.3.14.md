# 0.3.14 (2026-10-04, release)
- Windows: after Kodi crashed once, the next start no longer hangs on a black screen with just the cursor. The boot lock's dead-owner check used `os.kill(pid, 0)`, which is unusable on Windows (it raises a plain `OSError` for a missing pid and would even terminate a live one), so a stale lock was only stolen after 180 seconds. It now queries the process exit code via the Win32 API, so a lock left by a crashed session is taken over immediately.
- Windows: the source pill stays on the drive you are in. Navigating into a subfolder of a USB drive wrongly switched the pill to the user folder, because the drive-root detection only knew macOS `/Volumes`; it now recognises Windows drive letters (and UNC shares) with either slash direction and case-insensitive matching.
- Windows: the breadcrumb path now shows on local drives. It was built with forward slashes only, so a local `X:\\folder` path produced no segments (network sources already used forward slashes and worked); the segment split and the click-to-jump target now use the drive's own separator and are case-insensitive.
