# 0.3.16 (2026-10-04, release)
- On-screen keyboard: the delete (backspace) key and the hardware Backspace key now only delete -- with an empty field they no longer close the keyboard (close via its Cancel key or ESC/hardware Back).
- A stray click beside an input window no longer discards your typing: the network-source editor and the on-screen keyboard kept their full-screen backdrop as a close-on-click target; it is now inert, so a form/keyboard only closes via its Cancel/Back (the keyboard also has explicit OK/Cancel keys). The settings window has no context menu, so a right-click there is now inert -- it used to open the native context menu over the settings and push the source editor into the background (the Menu key is inert too while the editor or the folder picker is open).
- Added SFTP support: `sftp://` is a network source (source-editor protocol cycle, default port 22; needs the separate `vfs.sftp` addon). Browsing, audio/video playback and the photo viewer all work; it is read-only, like ftp/ftps, so write actions stay greyed out and the source editor's write toggle is disabled for it. Network folder listings are now requested with a trailing slash (Kodi's `vfs.sftp` builds child paths by appending the name to the folder string, so without it names came back folder-prefixed and `Stat` failed); this also covers the audio/photo playlists, the folder-size scan and the source test.
- WebDAV is faster: the server's authentication challenge is cached per origin, so listings, copies and uploads no longer make an extra unauthenticated probe request every time (a stalled probe could also burn Kodi's timeout). A stale Digest nonce is refreshed automatically on the next 401.
- The settings row menu (a network/drive/directory/blacklist/remote row's actions: toggle, edit, delete, cancel) now dims the settings behind it like every other dialog -- its full-screen backdrop had no veil, so the popup did not stand out from the rows behind it.
- The shutdown menu's dim backdrop now reaches the bottom on taller screens (16:10/3:2/4:3) -- the generated backdrop used a fixed 1152p height and left an undimmed bar at the bottom.
